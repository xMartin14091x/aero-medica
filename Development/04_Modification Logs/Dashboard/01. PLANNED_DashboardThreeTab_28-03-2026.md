## Problem
Current dashboard only shows class overview. No personal performance view, no per-scenario breakdown.

## Solution
3 main tabs: My Performance, Class Overview, Scenario Breakdown.

### Tab 1 — My Performance
- Personal radar chart (5 axes)
- Overall score, best axis, weakest axis
- Recent sessions list (per scenario, score + pass/fail)

### Tab 2 — Class Overview
- Existing: quick stats, class radar, weakest axis, student table
- Styled with ThemeMedical cards

### Tab 3 — Scenario Breakdown
- Scenario pill selector (Tutorial, RTA, Cardiac, MCI, Fire)
- Scenario-specific class radar
- Student results filtered to selected scenario

## Acceptance Criteria
- [ ] 3 tabs visible and switchable
- [ ] My Performance shows personal radar + session history
- [ ] Class Overview matches existing functionality with v2.0 styling
- [ ] Scenario Breakdown filters by scenario
- [ ] All data reads from HistoryManager
- [ ] ThemeMedical styling throughout
