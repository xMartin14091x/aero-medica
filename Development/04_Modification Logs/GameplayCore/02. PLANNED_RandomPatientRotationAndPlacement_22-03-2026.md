# MOD-GC-02 — Random Patient Rotation and Placement Offset

**Date:** 22-03-2026
**Requested by:** Chief Manager Martin
**Status:** `[>] DEFERRED` — Deferred post-competition. Patients use fixed positions per scenario JSON.
**Priority:** Medium

---

## Summary

Currently all patients spawn at fixed positions from scenario JSON with identical rotation (feet pointing the same direction). This looks unnatural. Patients should have:

1. **Random Y-axis rotation** — each patient lies facing a random direction
2. **Random position offset** — slight randomization around the spawn point (within a radius)

## Current Behavior

`scenario_manager.gd` spawns patients at exact positions from JSON `position` arrays. No rotation randomization. All patient models face default direction.

## Proposed Behavior

When spawning a patient entity:
1. Apply random Y-axis rotation: `entity.rotation_degrees.y = randf_range(0.0, 360.0)`
2. Apply random XZ offset within a small radius: `position += Vector3(randf_range(-1.0, 1.0), 0, randf_range(-1.0, 1.0))`
3. Ensure offset doesn't place patient inside collision geometry (vehicles, walls)

## Files

- `scripts/core/scenario_manager.gd` — patient spawn logic (add rotation + offset)

## Acceptance Criteria

- [ ] Each patient faces a different random direction on each scenario load
- [ ] Patients have slight positional variation (not identical positions every run)
- [ ] Patients don't clip into vehicles or environmental objects
- [ ] Tutorial patient (single) still spawns in a sensible location
