# MOD-GC-04 — Ollama Discovery Always-Probe + Startup Popup

**Date:** 29-03-2026
**Requested by:** Chief Manager Martin
**Status:** `[x] Complete`

---

## Problem
Both AI clients (`ollama_dialogue_client.gd`, `ollama_review_client.gd`) had a shortcut that assumed Ollama was available when a config URL was set, without actually probing. Game showed "AI Online" incorrectly. No user notification when Ollama was unavailable. Review client was missing `ollama_available` flag entirely.

## Solution
1. Removed config URL assumption — both clients now always probe all candidate addresses (config URL first, then localhost, 127.0.0.1, local network IPs)
2. Added `ollama_available` flag, `_probes_remaining` counter, and `_mark_discovery_failed()` to review client
3. Added styled in-game popup overlay on main menu when Ollama not found after 4s probe timeout
4. Added Reconnect button in Settings > AI section to re-trigger discovery on both clients
5. Added 6 bilingual translation keys (OLLAMA_POPUP_TITLE/MSG/CHECKED/OK, SETTINGS_AI_RECONNECT/RECONNECTING)
