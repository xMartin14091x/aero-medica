## Summary

Add a toggleable in-game medical reference panel with sectioned content. Accessible during gameplay without closing PatientInteractionUI. Provides paramedic-level reference material similar to a pocket reference card.

## Current State

No medical reference exists in-game. Protocol data (`bcls_protocol.json`, `als_protocol.json`, `start_triage.json`), drug data (`drugs.json`), ECG data (`ecg_rhythms.json`), and history templates (`history_questions.json`) exist as backend data only — not player-facing.

## Proposed Feature

### Access
- Hotkey toggle: **Tab** or **R** key (configurable)
- Also accessible via HUD button (book/reference icon)
- Can be opened alongside PatientInteractionUI (overlay, not mutually exclusive)
- Does NOT pause the timer (like real EMTs using pocket cards)

### Sections

| Section | Content Source | Format |
|---------|--------------|--------|
| DRSABCDE Primary Survey | Static text | Step-by-step checklist |
| START Triage Algorithm | `start_triage.json` | Flowchart/decision tree with color coding |
| SAMPLE History | Static text | Category descriptions + example questions |
| OPQRST Pain Assessment | Static text | Mnemonic + question guide |
| Vital Signs Reference | Static text | Normal ranges table with color coding |
| GCS Scale | Static text | Eye/Verbal/Motor scales with scores |
| Drug Quick Reference | `drugs.json` | Searchable table: drug name, route, dose, contraindications |
| ECG Rhythms | `ecg_rhythms.json` + textures | Rhythm name + description + sample image |
| BLS Protocol | `bcls_protocol.json` | Step sequence with critical actions highlighted |
| ALS Protocol | `als_protocol.json` | Step sequence with drug doses |

### UI Design
- Semi-transparent panel (right side or center overlay)
- Tab strip or accordion for sections
- Scrollable content per section
- Search/filter for Drug Reference section
- Close via same hotkey or Escape
