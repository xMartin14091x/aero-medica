# MOD-TS-01 — Interaction-Based Time Scaling

**Date:** 22-03-2026
**Requested by:** Chief Manager Martin
**Status:** `[ ] PENDING`
**Priority:** High (competition week)

---

## Summary

Modify the time pressure system so that time (and patient deterioration) runs SLOWER when patients are unattended — the player is NOT interacting with any patient. When the player IS actively assessing/treating a patient (PatientInteractionUI open), time flows at normal speed. This rewards active engagement, reduces idle stress, and makes the game accessible to both professionals and casual players.

## Current Behavior

`time_pressure_system.gd` counts down at fixed 1:1 rate. Deterioration rate escalates at 50% (1.5x) and 25% (2.0x) remaining, but the timer itself always ticks at the same speed regardless of player activity.

## Proposed Behavior

- **Idle/field mode** (walking around, no patient UI open): timer runs at **0.3x speed** (slow — patients wait while you navigate)
- **Interaction mode** (PatientInteractionUI visible, actively assessing): timer runs at **1.0x speed** (normal — real-time pressure during assessment)
- **Minimum time guarantee:** `time_limit = max(scenario_time, patient_count * 180)` — at least 3 minutes per patient
- Detection: check `Input.mouse_mode == Input.MOUSE_MODE_VISIBLE` (UI open = interacting = normal speed) vs `MOUSE_MODE_CAPTURED` (field mode = slow)

## Implementation Plan

### Ticket MOD-TS-01a — Time Scaling in TimePressureSystem
**Team:** Syndicate
**File:** `scripts/gameplay/time_pressure_system.gd`

1. Add `idle_time_scale` export var (default 0.3) — applied when player is NOT interacting
2. Add `_is_interacting: bool` tracker (true when PatientInteractionUI is open)
3. In `_process()`: if NOT interacting, multiply `delta` by `idle_time_scale` before adding to `_elapsed`; if interacting, use `delta` at 1.0x
4. Detect interaction state via `Input.mouse_mode` check: `MOUSE_MODE_VISIBLE` = interacting (1.0x), `MOUSE_MODE_CAPTURED` = idle (0.3x)
5. Deterioration schedule continues to apply on top of the time scale
6. DeteriorationSystem nodes also scale by the same factor (patients deteriorate slower while unattended)

### Ticket MOD-TS-01b — Minimum Time Guarantee in ScenarioManager
**Team:** Monolith
**File:** `scripts/core/scenario_manager.gd`

1. After loading `time_limit_seconds` from scenario JSON, apply floor: `max(time_limit, patient_count * 180.0)`
2. Tutorial (time_limit = 0) remains unlimited
