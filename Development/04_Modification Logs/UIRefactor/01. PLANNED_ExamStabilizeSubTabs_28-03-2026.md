# MOD-UI-01 — Exam & Stabilize Tab Sub-Tab Refactor

**Date:** 28-03-2026
**Requested by:** Chief Manager Martin + teammates (UX feedback: too cramped)
**Status:** `[x] Complete`

---

## Problem
Current Exam tab crams 5 sections (DRSABCDE, Vitals, ECG, GCS, Head-to-Toe) into one scrollable view. Stabilize tab crams equipment, drug admin, and triage together. Teammates report UI is "too tight and clumped together."

## Solution
Split heavy tabs into sub-tabs via horizontal pill buttons. Each sub-view shows only one focused section — no scrolling needed.

### Tab 2 — Exam Sub-Tabs
- **Primary** — DRSABCDE (8 cards, 4-column grid)
- **Vitals** — 8 vital sign cards + ECG panel
- **GCS** — Glasgow Coma Scale (3 rows: Eye, Verbal, Motor)
- **Head-to-Toe** — 7 region cards (2-column grid)

### Tab 3 — Stabilize Sub-Tabs
- **Equipment** — CPR button + Diagnostic (5) + Treatment (9), left/right split
- **Drug Admin** — Dropdowns left (1/4) + Log right (3/4)
- **Triage** — 4 large color-coded tag buttons + current assignment display

## Acceptance Criteria
- [ ] Exam tab shows 4 sub-tab pills, switching content without scroll
- [ ] Stabilize tab shows 3 sub-tab pills
- [ ] All existing button/dictionary references preserved
- [ ] Cooldown system works across sub-tab switches
- [ ] No regression on assessment/treatment/triage functionality
