# BUG-GC-04 — AI Reviewer Gives Incorrect Triage Feedback on Tutorial

**Date:** 22-03-2026
**Reported by:** Chief Manager Martin (live testing)
**Severity:** High
**Status:** `[x] Complete`

---

## Symptom

After completing the Tutorial scenario with correct actions per the cheat sheet (patient Somchai assessed, diagnosed correctly, GREEN triage assigned), the AI Reviewer states:

- "The student incorrectly assigned a GREEN tag to Somchai, who should have received a YELLOW or RED tag"
- "No treatments were applied to Somchai despite identifying injuries that require treatment"
- "Triage Tag Assignment" flagged as area for improvement
- Triage scored 0% accuracy

GREEN is the correct triage for tutorial Somchai (GCS 14, stable vitals, minor venous bleeding severity 1). The AI is providing clinically incorrect feedback.

## Root Cause

Two contributing factors:

1. **Triage accuracy calculation:** `_compute_triage_summary()` in `scenario_manager.gd:408-418` relies on `triage_assign` events having a `was_correct` field from `triage_system.gd`. The triage system computes the "correct" tag via `MedicalStateComponent.get_triage_priority()` which may not account for the tutorial patient's mild presentation correctly — or the START algorithm implementation may over-triage stable patients.

2. **AI hallucination:** The Ollama reviewer system prompt says "You do NOT need medical knowledge — the answer sheet tells you what the correct actions were." But the answer sheet sent via `_compose_user_prompt()` passes through the triage_summary with 0% accuracy from the buggy computation. The AI then constructs incorrect medical reasoning on top of wrong data.

## Fix

1. Verify `get_triage_priority()` in `medical_state_component.gd` returns GREEN for Somchai's vitals (HR 92, BP 128/82, SpO2 97%, GCS 14, bleeding_severity 1).
2. If the algorithm returns a different color, fix the START thresholds.
3. Add per-patient correct triage to the answer sheet so the reviewer doesn't need to infer.

## Files

- `scripts/medical/medical_state_component.gd` — verify get_triage_priority() for tutorial vitals
- `scripts/medical/triage_system.gd` — verify correct tag assignment
- `scripts/core/scenario_manager.gd` — include per-patient correct triage in answer sheet
- `scripts/ai/reviewer/ollama_review_client.gd` — pass per-patient correct triage in prompt

## Acceptance Criteria

- [ ] Triage accuracy calculation matches expected correct tags per scenario JSON
