# BUG-GC-07 — Player Cannot Move on First Scene Load

**Date:** 22-03-2026
**Reported by:** Chief Manager Martin (live testing)
**Severity:** Critical
**Status:** `[ ] PENDING`

---

## Symptom

When a scenario first loads, the player cannot move. Requires "Restart Scenario" from pause menu to initialize movement. After restart, movement works normally.

## Root Cause

Introduced by BUG-GC-02 fix. `player_controller.gd:81` added a guard:
```gdscript
if Input.mouse_mode == Input.MOUSE_MODE_VISIBLE:
    velocity = Vector3.ZERO
    move_and_slide()
    return
```

Godot's default `Input.mouse_mode` on scene load is `MOUSE_MODE_VISIBLE`. Nothing sets it to `MOUSE_MODE_CAPTURED` on initial scene start. The HUDController only sets CAPTURED in `_on_resume()` and `_on_restart()` — not on initial ready.

When "Restart Scenario" is triggered, `_on_restart()` calls `Input.mouse_mode = Input.MOUSE_MODE_CAPTURED`, which unblocks the guard.

## Fix

Set `Input.mouse_mode = Input.MOUSE_MODE_CAPTURED` at scene initialization. Best location: `hud_controller.gd:_ready()` or each level script's `_ready()`.

## Files

- `scripts/ui/hud_controller.gd` — add `Input.mouse_mode = Input.MOUSE_MODE_CAPTURED` in `_ready()`
