# BUG-GC-08 — RTA Map: Old Scene Active, V2 Editor Scene Not Wired

**Date:** 22-03-2026
**Reported by:** Chief Manager Martin (live testing)
**Severity:** High
**Status:** `[ ] PENDING`

---

## Symptom

When loading the Road Traffic Accident scenario, the floor is invisible — no road, no sidewalk, no grass ground. Vehicles, patients, and obstacles are present. Chief Manager Martin rebuilt the map in Godot editor with proper ground tiles.

## Root Cause

Two scenes exist:
- **Old:** `scenes/environments/RoadTrafficAccident.tscn` — bare skeleton, no ground tiles. This is what the game loads.
- **New (V2):** `scenes/gameplay/RoadTrafficAccidentV2.tscn` — Chief Manager Martin's editor-built scene with:
  - 1 large `Grass_Ground` tile (scaled ~91x73 units)
  - 4 road strips (2 horizontal, 2 vertical) extending beyond view
  - 8 sidewalk strips (all sides of intersection)
  - 4 invisible barriers
  - All vehicles, debris, cones properly placed under NavigationRegion3D
  - Proper spawn markers under `Spawns/` node

The game still loads the old scene. Additionally, `rta_level.gd` (attached to V2) still procedurally generates vehicles/debris/cones/spawns in `_ready()`, which would **duplicate** the editor-placed props.

## Fix

1. **Wire V2 as the active RTA scene.** Update scenario select and any level loading code to use `res://scenes/gameplay/RoadTrafficAccidentV2.tscn`
2. **Disable procedural prop generation in `rta_level.gd`** since V2 has everything placed manually. Comment out or guard: `_place_vehicles()`, `_place_debris()`, `_place_spawn_markers()`, `_place_emergency_vehicles()`, `_setup_traffic_hazard_zone()`. Keep `_load_scenario()` and camera wiring.
3. **Update `_load_scenario()` spawn reading** — V2 uses `Spawns/PatientSpawn_01` instead of `PatientSpawns/PatientSpawn_01`. Verify ScenarioManager finds the new spawn paths.

## Files

- `scripts/gameplay/rta_level.gd` — disable procedural placement, keep scenario loading
- `scripts/ui/scenario_select.gd` — update RTA scene path to V2
- `scripts/core/scenario_manager.gd` — verify spawn marker discovery works with V2 node structure

- [ ] RTA scenario loads V2 scene with visible ground, roads, sidewalks
- [ ] No duplicate props (no procedural + editor overlap)
- [ ] Patients spawn at V2's Spawns/ markers
- [ ] NavMesh bakes correctly with editor-placed geometry
- [ ] Emergency lights still animate
