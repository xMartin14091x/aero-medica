# BUG-GC-09 — Quit to Desktop Has No Confirmation Dialog

**Date:** 22-03-2026
**Reported by:** Chief Manager Martin (live testing)
**Severity:** Medium
**Status:** `[x] Complete`

---

## Symptom

In the pause menu during gameplay, clicking "Quit to Desktop" immediately quits the game without any "Are you sure?" confirmation dialog. This risks accidental loss of an in-progress scenario.

## Root Cause

`hud_controller.gd:264-265`:
```gdscript
func _on_quit_to_desktop() -> void:
    get_tree().quit()
```

No confirmation step before quitting.

## Fix

Add a confirmation dialog that appears when "Quit to Desktop" is pressed. Options: "Yes, Quit" and "Cancel". Cancel returns to pause menu.

## Files

- `scripts/ui/hud_controller.gd` — add confirmation step in `_on_quit_to_desktop()`

## Acceptance Criteria

- [ ] Clicking "Quit to Desktop" shows confirmation dialog
- [ ] "Yes, Quit" exits the game
- [ ] "Cancel" returns to pause menu
- [ ] Confirmation dialog uses consistent styling with existing UI

## Resolution
**Fixed in:** Phase 8
**Fix:** `main_menu.gd` now has a full quit confirmation dialog (`_build_quit_dialog()`, `_show_quit_dialog()`). Uses Window node with styled PanelContainer, confirm/cancel buttons. Player must explicitly confirm before the game exits.
