# BUG-GC-10 — Differential Diagnosis Categories Duplicating Per Patient

**Date:** 28-03-2026
**Reported by:** Chief Manager Martin (live testing)
**Severity:** High
**Status:** `[x] Complete`

---

## Symptom
Differential Diagnosis tab shows duplicating category sets — patient 1 shows 1 set, patient 2 shows 2 sets, patient 3 shows 3 sets. Only the latest set is interactive.

## Root Cause
`_populate_differential_tab()` appends new category containers without clearing old ones from the parent VBoxContainer. Each `open_ui()` call rebuilds categories but the previous patient's categories remain.

## Resolution
**Fixed in:** Session 1 (28-03-2026)
**Fix:** Clear all children from the differential content container before rebuilding in `_populate_differential_tab()`. Commit: `4280a2e`.
