# BUG-GC-11 — Dashboard Shows No Data (HistoryManager Save Pipeline Disconnected)

**Date:** 29-03-2026
**Reported by:** Chief Manager Martin (testing Dashboard after rework)
**Severity:** Critical
**Status:** `[x] Complete`

---

## Symptom
After completing a scenario and navigating to the Dashboard, no session data appears. Dashboard always shows empty state.

## Root Cause
`HistoryManager.save_session_scores()` was never called by any system. The scoring pipeline (ScoringEngine → HistoryManager) existed as code but was never wired. `ScenarioManager` built results and emitted `scenario_ended` but never persisted scores to disk.

## Resolution
**Fixed in:** Session 3 (29-03-2026)
**Fix:** Added `_save_session_to_history(results)` call in `scenario_manager.gd` after `scenario_ended.emit()`. New function instantiates ScoringEngine + ProtocolAdherenceTracker, computes 5-axis scores, saves via HistoryManager. Includes fallback basic scoring. Also fixed HistoryManager autoload path in `project.godot` (`scripts/core/` → `scripts/dashboard/`). Commit: `8e8f53c`.
