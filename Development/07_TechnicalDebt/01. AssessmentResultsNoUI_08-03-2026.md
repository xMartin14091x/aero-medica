# Technical Debt: Assessment Results Have No Visual Feedback

**Logged:** 08-03-2026
**Severity:** Medium — system works internally but player sees nothing
**Related Bug Fix:** `05_BugFixesLog/GameplayCore/01. IMPLEMENTED_ScenarioLoadingAndInteractions_08-03-2026.md`

---

## Problem

When the player assesses a patient (presses E → selects "Check Airway" / "Check Pulse" / etc.), the assessment is:
- Computed correctly by `AssessmentManager.perform_assessment()`
- Stored on the patient via `patient.set_meta("assessed_conditions", {...})`
- Logged to telemetry via `TelemetryEmitter`
- Emitted via `assessment_performed` signal

But **no UI element displays the result** to the player. The `assessment_performed` signal is not connected to any visual component. The player clicks "Check Pulse" and gets no feedback — no text saying "Pulse: Present" or "Pulse: Absent".

## Current Signal Flow

```
Player presses E on patient
  → InteractionManager._interact_with_target()
  → AssessmentManager.begin_assessment(patient)
  → HUDController._on_assessment_started()
  → ActionMenu.open_menu(patient)
  → Player selects "Check Airway"
  → ActionMenu.action_selected signal
  → HUDController._on_action_selected()
  → AssessmentManager.perform_assessment_by_name("Check Airway")
  → Returns { "airway_status": "CLEAR" }  ← THIS IS NEVER SHOWN
  → assessment_performed signal emitted  ← NOTHING LISTENS
  → ActionMenu.close_menu()  ← Menu closes, no result displayed
```

## Proposed Fix

Wire `assessment_performed` in `HUDController` to display a temporary result panel showing the assessment findings. Could reuse the hint panel pattern (show for 3-5 seconds, then auto-hide), or add a persistent patient info panel while in assessment mode.

## Impact If Not Fixed

Players cannot learn patient status through gameplay — the core loop is broken from a UX perspective even though the backend works correctly.
