# Technical Debt: SyncThing Deletes Binary Assets

**Logged:** 08-03-2026
**Severity:** Low — manual workaround exists (re-copy file)
**Occurrences:** `doctor.glb` and 8 texture PNGs wiped from `assets/models/characters/`

---

## Problem

SyncThing syncs the project between machines. Binary asset files (`.glb`, `.png`) are being deleted during sync — only the Godot `.import` metadata files survive. This has happened at least once with the doctor character model.

## Proposed Fix

Add the following to `.stignore` at the project root:

```
.godot/
*.import
```

Or alternatively, keep binary assets outside the SyncThing folder and symlink them into the Godot project.

## Current Workaround

Re-copy deleted files from Downloads or original source. The `.import` files remain valid — Godot re-imports automatically when the source file reappears.
