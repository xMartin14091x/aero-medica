## วัตถุประสงค์การเรียนรู้ของโปรเจกต์คุณคืออะไร?

เพื่อให้ผู้เล่นได้เรียนรู้และฝึกฝน "กระบวนการประเมินและรักษาผู้ป่วยฉุกเฉินอย่างเป็นระบบ" ตามมาตรฐาน EMS สากล ผ่านสถานการณ์จำลอง 3 มิติที่สมจริง โดยครอบคลุมทักษะ Primary Survey (DRSABCDE), การซักประวัติ (SAMPLE/OPQRST), การอ่าน Vital Signs, การคัดแยกผู้ป่วย (START Triage), และการตัดสินใจให้ยา — ซึ่งเกมอื่นในตลาดยังไม่สามารถจำลองความลึกของกระบวนการเหล่านี้ได้ครับ (≧◡≦)

---

## เกมเพลย์ช่วยสนับสนุนการเรียนรู้ในระบบของคุณอย่างไร?

ผู้เล่นเรียนรู้ผ่าน "การลงมือทำ" ในสถานการณ์จำลองที่มีความกดดันด้านเวลาเหมือนจริง:

1. **ประเมินผู้ป่วย** — ตรวจร่างกายตามลำดับ DRSABCDE, วัด Vital Signs (ชีพจร, ความดัน, SpO2, อุณหภูมิ), ประเมิน GCS (Glasgow Coma Scale), และตรวจร่างกายทุกส่วน (Secondary Survey)
2. **ซักประวัติ** — สัมภาษณ์ผู้ป่วยด้วยหลัก SAMPLE และ OPQRST โดยมี AI ออฟไลน์ (Ollama) สร้างบทสนทนาแบบไดนามิก ผู้ป่วยที่ไม่รู้สึกตัวจะไม่ตอบ — ต้องหาข้อมูลจากผู้เห็นเหตุการณ์แทน
3. **รักษาและให้ยา** — เลือกอุปกรณ์จาก Medical Bag (แบ่งระดับ BLS/ALS), ให้ยาโดยต้องเลือกขนาดยาและช่องทางให้ถูกต้อง ระบบจะติดตาม Medication Error เพื่อสอนในขั้นตอน Debrief
4. **คัดแยกผู้ป่วย (Triage)** — ในสถานการณ์ผู้บาดเจ็บจำนวนมาก (MCI) ผู้เล่นใช้ START Triage แบ่งผู้ป่วยเป็น 4 ระดับสี (RED/YELLOW/GREEN/BLACK) ภายใน 30 วินาทีต่อคน
5. **วินิจฉัยและสรุปผล** — เลือกการวินิจฉัยจากรายการ แล้วรับ Debrief Score ที่ประเมินความถูกต้องของทุกขั้นตอน

สภาพผู้ป่วยจะแย่ลงตามเวลาจริง (Deterioration System) — ถ้าผู้เล่นไม่รักษาทันเวลา ผู้ป่วยอาจเสียชีวิตได้ครับ

## ปัญหาในโลกความเป็นจริงที่คุณกำลังแก้ไขคืออะไร?

การฝึกรับมือสถานการณ์ฉุกเฉินทางการแพทย์ในปัจจุบันต้องอาศัยหุ่นจำลอง อุปกรณ์เฉพาะทาง และผู้สอนที่มีความเชี่ยวชาญ — ทำให้มีค่าใช้จ่ายสูงและเข้าถึงได้ยาก บุคคลทั่วไปจึงไม่มีพื้นที่ปลอดภัยในการฝึกฝนว่าควรทำอย่างไรเมื่อพบเจอผู้ป่วยฉุกเฉิน AeroMedica แก้ปัญหานี้โดยเปลี่ยนคอมพิวเตอร์ทุกเครื่องให้เป็นห้องจำลองสถานการณ์ — ไม่ต้องอินเทอร์เน็ต ไม่ต้องซื้ออุปกรณ์ ไม่ต้องมีผู้สอนครับ (╥﹏╥)

## กลุ่มเป้าหมาย – หลักและรอง

**กลุ่มเป้าหมายหลัก:** บุคคลทั่วไป ผู้ที่ชื่นชอบด้านการแพทย์ และเกมเมอร์ที่อยากได้รับความรู้ (B2C)

**กลุ่มเป้าหมายรอง:** บุคลากรทางการแพทย์มืออาชีพ และผู้เข้ารับการฝึกอบรม (B2B)

---

## ผลกระทบที่คาดหวัง: สังคม / การศึกษา / เศรษฐกิจ

ในด้านสังคมและการศึกษา โปรเจกต์นี้จะช่วยกระจายความรู้ด้านการแพทย์และการปฐมพยาบาลที่ถูกต้องไปสู่คนหมู่มาก และคาดหวังว่าจะเป็นจุดประกายให้ผู้คนจำนวนมากเกิดความหลงใหลและสนใจที่จะก้าวเข้าสู่วิชาชีพแพทย์หรือผู้กู้ชีพในอนาคตครับ

## เทคโนโลยีที่จะใช้

เอนจินเกม Godot 4.6 (GDScript) สำหรับสร้างสภาพแวดล้อม 3 มิติและระบบจำลองทางการแพทย์ ประกอบด้วย Patient State Machine ที่จำลองสภาวะผู้ป่วย (สัญญาณชีพ, คลื่นไฟฟ้าหัวใจ, GCS), Protocol Validation ที่ตรวจสอบลำดับการรักษาตามมาตรฐาน EMS, และ Deterioration System ที่ทำให้อาการผู้ป่วยแย่ลงตามเวลาจริง ข้อมูลสถานการณ์จำลองขับเคลื่อนด้วย JSON ทั้งหมด ระบบ AI ใช้ Ollama แบบออฟไลน์สำหรับบทสนทนาผู้ป่วยที่ไม่ซ้ำกัน — ไม่ต้องเชื่อมต่ออินเทอร์เน็ตครับ

## ทำไม Metaverse ถึงจำเป็นสำหรับโปรเจกต์นี้?

การเรียนรู้การแพทย์ฉุกเฉินจากตำราหรือวิดีโอไม่เพียงพอ — ผู้เรียนต้อง "อยู่ในสถานการณ์" เพื่อฝึกการตัดสินใจภายใต้ความกดดัน สภาพแวดล้อม 3 มิติแบบอินเทอร์แอคทีฟช่วยจำลอง Spatial Awareness (ต้องเดินไปหาผู้ป่วย หยิบอุปกรณ์ จัดลำดับความสำคัญ), Time Pressure (สภาพผู้ป่วยแย่ลงแบบ Real-time), และ Physical Interaction (ทำ CPR, ติด AED, อ่าน ECG, ให้ยา) ที่สื่อ 2 มิติไม่สามารถจำลองได้ครับ

---

## โครงสร้างเทคโนโลยี / เครื่องมือ

- **Game Engine:** Godot 4.6 (GDScript) — สร้างโลก 3D, ระบบฟิสิกส์, UI
- **Medical Simulation Core:** Patient State Machine (CONSCIOUS → UNCONSCIOUS → CARDIAC_ARREST → DEAD), Vital Signs Model (HR, BP, SpO2, GCS, ECG), Deterioration System (อาการแย่ลงตามเวลาจริง)
- **Clinical Protocol Engine:** DRSABCDE Assessment, START Triage Algorithm, Protocol Validation (ตรวจสอบลำดับการรักษาที่ถูกต้อง), Drug Administration with Error Tracking
- **AI Dialogue:** Ollama (HTTP REST, ออฟไลน์) — สร้างบทสนทนาผู้ป่วยแบบไดนามิก
- **Data Layer:** JSON-driven scenarios (ข้อมูลผู้ป่วย, ประวัติ SAMPLE/OPQRST, vital signs, ECG rhythms, examination findings, drug database)
- **Analytics:** Telemetry Pipeline — บันทึกทุกการกระทำของผู้เล่นเพื่อสร้าง Debrief Score และ Protocol Adherence Report
